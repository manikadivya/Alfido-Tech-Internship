\# 📊 Superstore Sales Analysis



\## Alfido Tech Internship – Task 1



\## Project Overview



This project analyzes the Superstore Sales dataset to understand sales performance across different regions, product categories, products, and time periods. The analysis includes data cleaning, exploratory data analysis (EDA), key performance indicators (KPIs), and business recommendations.



\---



\## Objectives



\* Clean and prepare the sales dataset.

\* Perform exploratory data analysis.

\* Calculate important business KPIs.

\* Visualize sales trends and regional performance.

\* Identify top-performing products and categories.

\* Provide actionable business recommendations.
